## English

Madara V2 builds on the first version and represents another stage of experimentation with combat behavior. It has its own branch so the changes can be evaluated without replacing V1.

When comparing the two, the interesting questions are practical: does the robot survive longer, avoid shots more consistently, and hit moving targets more often? A single win is not enough to answer those questions, so repeated rounds matter.

### Run in Robocode

Compile `MadaraV2.java` in Robocode, then test against a fixed group of opponents. Compare the results with V1 under the same conditions.

## Português

Madara V2 parte da primeira versão e representa outra etapa dos experimentos com o comportamento em combate. Ela fica em uma branch separada para que suas mudanças possam ser avaliadas sem substituir a V1.

Na comparação, o que importa é o resultado em batalha: o robô sobrevive mais, desvia melhor e acerta alvos em movimento com mais frequência? Uma vitória isolada não responde isso; vale observar várias rodadas.

### Como executar no Robocode

Compile `MadaraV2.java` no Robocode e teste contra um grupo fixo de adversários. Compare os resultados com a V1 nas mesmas condições.
