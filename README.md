## English

This experimental branch explores how Madara V3 handles fights with several opponents at once. In a crowded arena, a safe route can become dangerous in moments: bullets, enemy positions, and nearby walls all affect the next movement.

Changes are kept here while they are being tested, so they do not automatically become part of the standard V3 version. The interesting measure is not a single spectacular dodge but how consistently the robot survives over many battles.

### Run in Robocode

Check out this branch, open `MadaraV3.java` in the Robocode editor, and compile. Test against the same set of opponents across multiple rounds; track survival, damage, and placement before drawing conclusions.

## Português

Esta branch experimental explora como o Madara V3 se movimenta em combates com vários adversários ao mesmo tempo. Em uma arena cheia, um caminho seguro pode deixar de ser seguro rapidamente: tiros, posições dos inimigos e paredes próximas mudam a decisão de movimento.

As alterações ficam isoladas enquanto são testadas, sem entrar automaticamente na versão normal da V3. O que interessa não é um desvio impressionante, mas a capacidade de sobreviver de forma consistente ao longo de muitas batalhas.

### Como executar no Robocode

Faça checkout desta branch, abra `MadaraV3.java` no editor do Robocode e compile. Teste com o mesmo grupo de adversários por várias rodadas e observe sobrevivência, dano e colocação antes de tirar conclusões.

**Código-fonte:** [MadaraV3.java](./MadaraV3.java)
