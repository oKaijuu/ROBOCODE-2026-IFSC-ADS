## Overview

**Madara V3** is the experimental branch for iterating on robot behavior and combat strategy without mixing those changes into the main development line. The goal is to build a robot that can respond to changing battle conditions instead of relying on one fixed movement or firing pattern.

> *“Those who cannot acknowledge their true selves are bound to fail.”*

## Repository

- **Repository:** [ROBOCODE-2026-IFSC-ADS](https://github.com/oKaijuu/ROBOCODE-2026-IFSC-ADS)
- **Experimental branch:** `experiment/madara-v3-melee-movement`
- **Main robot file:** `MadaraV3.java`
- **Platform:** [Robocode](https://robocode.sourceforge.io/)

## Run the experiment

1. Clone this branch:
   ```bash
   git clone --branch experiment/madara-v3-melee-movement --single-branch https://github.com/oKaijuu/ROBOCODE-2026-IFSC-ADS.git
   ```
2. Open the project in your Robocode development environment.
3. Compile `MadaraV3.java` and run battles against a consistent set of opponents.
4. Compare results across multiple rounds before judging a strategy change.

## Evaluation notes

Battle results can vary significantly with opponent selection, arena conditions, and random behavior. For meaningful comparisons, keep the test setup consistent and record win rate, survival time, damage dealt, and final ranking across repeated battles.
