## Overview

Madara V2 is maintained as a separate generation to make its implementation and battle behavior easier to review against V1 and V3.

## Evaluation workflow

- Compile `MadaraV2.java` in Robocode.
- Test it against the same opponents and battle settings used for the other versions.
- Compare survival, targeting effectiveness, movement, and final ranking across multiple rounds.
- Keep changes specific to V2 on this branch to preserve version-to-version comparisons.
