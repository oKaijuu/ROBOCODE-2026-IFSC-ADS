## 戦略 // DESIGN PHILOSOPHY

</div>

Madara V3 is developed on an isolated experimental branch so movement and combat ideas can be tested without mixing unfinished changes into the main line. The objective is to evaluate behavior under pressure, especially in multi-robot battles where threats and positioning change quickly.

> *“Wake up to reality.”*

**Experimental means unproven.** Features and strategies remain works in progress until repeated, comparable battles show measurable improvement.

<div align="center">

## 起動 // RUN THE EXPERIMENT

</div>

**1. Clone only this branch**

```bash
git clone --branch experiment/madara-v3-melee-movement --single-branch https://github.com/oKaijuu/ROBOCODE-2026-IFSC-ADS.git TriStateRobots
```

**2. Launch Robocode**

Open the project in your Robocode development environment and compile `MadaraV3.java`.

**3. Test consistently**

Use the same opponent set and arena conditions across multiple rounds. Compare win rate, survival time, damage dealt, and final placement before deciding whether a change helped.
